# Sales-analytics-sql-
# Understanding Customer Behavior Through POS Data Analysis

## 📌 Project Overview

This project analyzes **Point-of-Sale (POS) data** from a retail company to understand customer purchasing behavior, transaction patterns, revenue performance, return trends, and product category performance.

The project demonstrates how raw CSV datasets can be transformed into a **structured relational database using MySQL** and analyzed using SQL queries to generate meaningful business insights.

The analysis focuses on customer demographics, transaction behavior, revenue, returns, product categories, store performance, and time-based trends.

---

## 🎯 Objectives

The main objectives of this project are to:

- Build a structured `Customer_Behavior` database in MySQL
- Import and validate three CSV datasets
- Clean and prepare the data for analysis
- Analyze customer demographics and purchasing behavior
- Analyze transaction channels and store performance
- Calculate revenue and return metrics
- Identify high-performing categories and sub-categories
- Perform time-based and comparative revenue analysis
- Generate actionable business insights using SQL

## 🗄️ Database Structure

The project database is named:

```sql
Customer_Behavior
```

The database contains three main tables:

```text
Customer_Behavior
│
├── customer
│
├── transactions
│
└── product_category
```

### Relationship

The tables are connected using customer IDs and product category/sub-category codes.

```text
Customer
   │
   │ customer_Id = cust_id
   ▼
Transactions
   │
   │ prod_cat_code
   │ prod_subcat_code
   ▼
Product Category
```

## 🚀 How to Run the Project

### Step 1 — Install MySQL

Install MySQL Server and MySQL Workbench.

### Step 2 — Create the Database

Run:

```sql

USE Customer_Behavior;
```

### Step 3 — Import the CSV Files

Import the three datasets into MySQL Workbench:

- `Customer.csv`
- `Transactions.csv`
- `prod_cat_info.csv`

### Step 4 — Run the SQL Analysis

Open:


Run the queries sequentially.
